# `@metamask/node-utils`

Utilities for Node.js environments, such as filesystem access and test sandboxing

## Installation

`yarn add @metamask/node-utils`

or

`npm install @metamask/node-utils`

## Contributing

This package is part of a monorepo. Instructions for contributing can be found in the [monorepo README](https://github.com/MetaMask/core#readme).
