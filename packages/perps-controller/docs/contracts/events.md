# Perps analytics events

Perps sends a fixed set of events. A new tracking need adds a property, or a value of an existing property, to one of these events. It never adds an event. Every property and value comes from these constants and means the same thing on every event and every client.

Mobile's hooks, enrichment, local values and A/B registry are in [metamask-mobile/docs/perps/instrumentation.md](https://github.com/MetaMask/metamask-mobile/blob/main/docs/perps/instrumentation.md).

## How Core emits

- Core calls `trackPerpsEvent(event, properties)` on the injected `metrics` dependency. The client maps the call to its analytics backend.
- Services call `this.#deps.metrics.trackPerpsEvent`. `PerpsController` calls it through `#getMetrics()`.
- `asset` is the order's `symbol`. `completion_duration` is measured with the injected `performance.now()`, in milliseconds.
- Core adds no `timestamp` to its events.

Code: `src/types/index.ts` `PerpsMetrics`, `PerpsPlatformDependencies`; `src/PerpsController.ts` `#getMetrics`; `src/services/TradingService.ts`; `src/services/AccountService.ts`

## Shared property groups

`TradingService` builds these groups once and spreads them into several events.

| Group        | Properties                                                                                               | Present when                                                                                                                                                                                        |
| ------------ | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Trade intent | `order_type`, `reduce_only`                                                                              | Every trade event. `reduce_only` is `true` only when the order sets `reduceOnly`                                                                                                                    |
| Slippage     | `max_slippage_pct`, `max_slippage_source`, `estimated_slippage_pct`, `failure_reason`, `price_delta_bps` | Each key only when the caller or the result supplies it. `failure_reason` is the error code from the result or from a thrown `PerpsControllerError`. `price_delta_bps` only for a price-moved error |
| Attribution  | `entry_point`, `discovery_source`, `perp_discovery_source`, `hl_fee_rate`, `environment_type`            | Each key only when the caller's `trackingData` has it                                                                                                                                               |

Code: `src/services/TradingService.ts` `#buildTradeIntentProperties`, `#buildSlippageProperties`, `#buildAttributionProperties`; `src/services/environmentTypeProperty.ts` `environmentTypeProperty`

## Perp Trade Transaction

`placeOrder` emits `submitted` before the provider call, then `executed` or `failed`. A partial fill also emits `partially_filled` before the final event.

| Property                                                                                                                | Constant                                                                                                                | Carried on                                                                                                                        |
| ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `status`                                                                                                                | `STATUS`                                                                                                                | All. `submitted`, `executed`, `partially_filled`, `failed`                                                                        |
| `asset`                                                                                                                 | `ASSET`                                                                                                                 | All                                                                                                                               |
| `direction`                                                                                                             | `DIRECTION`                                                                                                             | All. `long` or `short`                                                                                                            |
| `leverage`                                                                                                              | `LEVERAGE`                                                                                                              | All                                                                                                                               |
| Trade intent group                                                                                                      |                                                                                                                         | All                                                                                                                               |
| Slippage group                                                                                                          |                                                                                                                         | All                                                                                                                               |
| Attribution group                                                                                                       |                                                                                                                         | All                                                                                                                               |
| `order_size`                                                                                                            | `ORDER_SIZE`                                                                                                            | Result events. Filled size, else accepted, submitted, then requested size. A zero filled size uses the accepted size when present |
| `completion_duration`                                                                                                   | `COMPLETION_DURATION`                                                                                                   | Result events                                                                                                                     |
| `trade_with_token`                                                                                                      | `TRADE_WITH_TOKEN`                                                                                                      | Result events                                                                                                                     |
| `mm_pay_token_selected`                                                                                                 | `MM_PAY_TOKEN_SELECTED`                                                                                                 | Result events with tracking data. Token symbol, or `Perps Balance` (`MM_PAY_TOKEN.PERPS_BALANCE`)                                 |
| `mm_pay_network_selected`                                                                                               | `MM_PAY_NETWORK_SELECTED`                                                                                               | Result events, when paying with a token                                                                                           |
| `margin_used`, `fees`, `asset_price`, `limit_price`, `source`, `chart_library`, `action`, `order_value`                 | `MARGIN_USED`, `FEES`, `ASSET_PRICE`, `LIMIT_PRICE`, `SOURCE`, `CHART_LIBRARY`, `ACTION`, `ORDER_VALUE`                 | Result events, when known                                                                                                         |
| `vip_tier`, `vip_discount`, `ab_tests`                                                                                  | `VIP_TIER`, `VIP_DISCOUNT`, `AB_TESTS`                                                                                  | Result events, when the caller passes them                                                                                        |
| `metamask_fee`, `metamask_fee_rate`, `discount_percentage`, `estimated_rewards`, `take_profit_price`, `stop_loss_price` | `METAMASK_FEE`, `METAMASK_FEE_RATE`, `DISCOUNT_PERCENTAGE`, `ESTIMATED_REWARDS`, `TAKE_PROFIT_PRICE`, `STOP_LOSS_PRICE` | `executed` and `partially_filled`, when known                                                                                     |
| `error_message`                                                                                                         | `ERROR_MESSAGE`                                                                                                         | `failed`                                                                                                                          |
| `amount_filled`, `remaining_amount`                                                                                     | `AMOUNT_FILLED`, `REMAINING_AMOUNT`                                                                                     | `partially_filled`. `order_size` there is the accepted size                                                                       |

`editOrder` emits `executed` or `failed` with `status`, `asset`, `direction`, the trade intent group, `leverage`, `order_size`, `completion_duration` and `environment_type`. `executed` adds `limit_price` when the order has a price. `failed` adds `error_message`.

`flipPosition` emits `submitted`, then `executed` or `failed`, with `action` set to `flip_long_to_short` or `flip_short_to_long`, `order_type` set to `market` and the attribution group. `submitted` and `executed` carry `direction`, `leverage` and `order_size` (the position size). `executed` adds `completion_duration`, `order_value`, `metamask_fee`, `vip_tier` and `vip_discount`. `failed` carries `completion_duration`, `error_message`, `vip_tier` and `vip_discount`, with no `direction`.

Core never sets `input_method` on this event.

Code: `src/services/TradingService.ts` `placeOrder`, `#trackOrderResult`, `editOrder`, `flipPosition`

## Perp Position Close Transaction

`closePosition` emits `submitted` with `status`, `asset`, `order_type`, the slippage and attribution groups and `bulk_action_id`. The result is `executed` or `failed`, plus `partially_filled` for a partial fill.

| Property                                                                                                                                                                                     | Constant                                                                                                                                                                                     | Carried on                                                                         |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `status`, `asset`, `order_type`                                                                                                                                                              | `STATUS`, `ASSET`, `ORDER_TYPE`                                                                                                                                                              | Per-position events                                                                |
| `direction`, `order_size`, `close_type`, `open_position_size`, `percentage_closed`                                                                                                           | `DIRECTION`, `ORDER_SIZE`, `CLOSE_TYPE`, `OPEN_POSITION_SIZE`, `PERCENTAGE_CLOSED`                                                                                                           | Result events with a local position                                                |
| `dollar_pnl`, `percent_pnl`                                                                                                                                                                  | `PNL_DOLLAR`, `PNL_PERCENT`                                                                                                                                                                  | Result events, when the position has them                                          |
| `leverage`                                                                                                                                                                                   | `LEVERAGE`                                                                                                                                                                                   | Result events with a local position. Position value divided by margin, one decimal |
| `fee`, `metamask_fee`, `metamask_fee_rate`, `discount_percentage`, `estimated_rewards`, `asset_price`, `limit_price`, `received_amount`, `source`, `vip_tier`, `vip_discount`, `order_value` | `FEE`, `METAMASK_FEE`, `METAMASK_FEE_RATE`, `DISCOUNT_PERCENTAGE`, `ESTIMATED_REWARDS`, `ASSET_PRICE`, `LIMIT_PRICE`, `RECEIVED_AMOUNT`, `SOURCE`, `VIP_TIER`, `VIP_DISCOUNT`, `ORDER_VALUE` | Result events, when known                                                          |
| Slippage and attribution groups                                                                                                                                                              |                                                                                                                                                                                              | Per-position events                                                                |
| `completion_duration`                                                                                                                                                                        | `COMPLETION_DURATION`                                                                                                                                                                        | Result events                                                                      |
| `error_message`                                                                                                                                                                              | `ERROR_MESSAGE`                                                                                                                                                                              | `failed`                                                                           |
| `amount_filled`, `remaining_amount`                                                                                                                                                          | `AMOUNT_FILLED`, `REMAINING_AMOUNT`                                                                                                                                                          | `partially_filled`                                                                 |
| `bulk_action_id`                                                                                                                                                                             | `BULK_ACTION_ID`                                                                                                                                                                             | Events from a batch close                                                          |

Trade events send the fee as `fees` and close events send it as `fee`. This is a known inconsistency: both keys are already emitted, so any rename is left to the analytics owners.

When Core has no local position record, the result event carries only `status`, `asset`, `order_type`, `completion_duration`, `error_message`, the slippage and attribution groups and `bulk_action_id`. It has no `direction` or `open_position_size`.

`closePositions` adds one summary event with `status`, `order_type` (`market`), `completion_duration`, `bulk_action_id`, `number_positions_closed` and, on error, `error_message`.

Core never sets `input_method` on this event.

Code: `src/services/TradingService.ts` `closePosition`, `closePositions`, `#trackPositionCloseResult`, `#buildCloseEventProperties`

## Perp Withdrawal Transaction

| Status      | Meaning                              | Properties                                                                      | Emitter                                                                   |
| ----------- | ------------------------------------ | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |

## Perp Risk Management

TP/SL writes emit `submitted` with `status`, `asset`, `source` and the attribution group, then one `executed` or `failed` event.

| Property                                                                                                               | Constant                                                                                                               | Carried on                                                 |
| ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `status`, `asset`, `source`                                                                                            | `STATUS`, `ASSET`, `SOURCE`                                                                                            | All. `source` defaults to `tp_sl_view`                     |
| `completion_duration`                                                                                                  | `COMPLETION_DURATION`                                                                                                  | Result event                                               |
| `screen_type`                                                                                                          | `SCREEN_TYPE`                                                                                                          | Result event. `create_tpsl` or `edit_tpsl`                 |
| `has_take_profit`, `has_stop_loss`                                                                                     | `HAS_TAKE_PROFIT`, `HAS_STOP_LOSS`                                                                                     | Result event                                               |
| `action`                                                                                                               | `ACTION`                                                                                                               | Result event, when a TP or SL is set. `tp`, `sl` or `tpsl` |
| `direction`, `position_size`, `take_profit_price`, `stop_loss_price`, `take_profit_percentage`, `stop_loss_percentage` | `DIRECTION`, `POSITION_SIZE`, `TAKE_PROFIT_PRICE`, `STOP_LOSS_PRICE`, `TAKE_PROFIT_PERCENTAGE`, `STOP_LOSS_PERCENTAGE` | Result event, when known                                   |
| `error_message`                                                                                                        | `ERROR_MESSAGE`                                                                                                        | `failed`                                                   |
| Attribution group                                                                                                      |                                                                                                                        | All                                                        |

`updateMargin` emits no `submitted` event. Its `executed` or `failed` event carries `status`, `asset`, `action` (`add_margin` or `remove_margin`), `margin_used` (the absolute amount), `completion_duration` and, on failure, `error_message`.

Code: `src/services/TradingService.ts` `updatePositionTPSL`, `replacePositionTPSLLeg`, `#writePositionTpsl`, `updateMargin`

## Perp UI Interaction

| `interaction_type`       | Other properties                                                                                           | Emitter                                                                 |
