# `@metamask/profile-controller`

Controller for managing user profile data including username, bio, avatar, and linked accounts via the MetaMask Profile API.

## Installation

`yarn add @metamask/profile-controller`

or

`npm install @metamask/profile-controller`

## Contributing

This package is part of a monorepo. Instructions for contributing can be found in the [monorepo README](https://github.com/MetaMask/core#readme).
