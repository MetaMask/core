# `@metamask/assets-controller`

Tracks assets balances/prices and handles token detection across all digital assets.

Live spot prices (backend stream, `MarketStatsService`, this controller,
Extension UI) are described in [docs/decisions/2026-11-05-market-stats.md](./docs/decisions/2026-11-05-market-stats.md).

## Installation

`yarn add @metamask/assets-controller`

or

`npm install @metamask/assets-controller`

This package is part of a monorepo. Instructions for contributing can be found in the [monorepo README](https://github.com/MetaMask/core#readme).
